# Security policy

This is an experimental root/LSPosed module. No formal security support or response-time guarantee is offered.

If you find a vulnerability that could expose data or perform privileged operations without consent, **do not include exploit payloads, device identifiers, or private logs in a public GitHub issue.** Contact the maintainer privately through a security-advisory reporting channel **if that repository enables private vulnerability reporting**. Until then, do not post sensitive details publicly.

Do not install an APK from an untrusted third party. Public releases should be signed with the maintainer's stable signing key, distinct from debug keys.
