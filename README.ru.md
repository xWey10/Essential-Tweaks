# Essential Tweaks

[English](README.md) · **Русский**

Essential Tweaks — неофициальный LSPosed-модуль для Nothing OS на Android 16. Он добавляет отдельные настройки штатного интерфейса, **не заменяя System UI целиком**.

**Версия:** 0.2.19 · **Лицензия:** [GPL-3.0-only](LICENSE) · **Статус:** экспериментальный

Проект не связан с Nothing или CMF и не поддерживается ими. После обновлений прошивки системные хуки могут перестать работать — включайте и проверяйте функции по отдельности.

## Возможности

- **Меню питания:** Recovery, Bootloader и перезапуск SystemUI в штатном меню, без `su`. Для Recovery/Bootloader необходимы системные разрешения у SystemUI; без них действие недоступно.
- **Essential Key:** отдельное действие для нажатия, двойного нажатия, удержания и составных жестов: скриншот, запись экрана, запуск выбранного приложения, запуск экспортируемой Activity, диктофон, камера, раскрытие шторки. Оригинальное поведение Nothing можно восстановить (может потребоваться `su` для управления Essential Space/Recorder).
- **Диктофон:** первое нажатие запускает запись звука без перехода в приложение, следующее сохраняет файл. При назначенном жесте появляются настройки формата (M4A/AAC, OGG/Opus или 3GP/AMR), качества, места сохранения (Music, Recordings, собственная папка) и имени файла с шаблонами `{date}`, `{time}`, `{datetime}`, `{epoch}`. По умолчанию файлы сохраняются в `Music/EssentialTweaks`. Разрешение на микрофон необходимо выдать через настройки Essential Tweaks до использования кнопки; во время записи Android показывает системный индикатор и уведомление. Ограничения Android 16 могут помешать запуску микрофонного сервиса из фона на отдельных прошивках — работа без перехода в приложение требует проверки на устройстве.
- **Строка состояния:** горизонтальный свайп регулирует яркость (переключает автояркость в ручной режим), секунды в системных часах, двойное касание для выключения экрана.
- **Индикатор отпечатка:** изображение вместо индикатора подэкранного сканера в режиме ожидания и выбор цвета точек сканирования.
- **Экран блокировки:** напряжение, ток, мощность и температура зарядки; двойное касание для пробуждения/выключения экрана.
- **Скриншоты:** необязательный хук `FLAG_SECURE` в System Framework. Не обходит DRM и не гарантирует захват любого приложения; по умолчанию выключен.
- **Обновления:** проверка GitHub Releases при открытии приложения с сообщением **только внутри приложения**. Без уведомлений, фоновых служб обновления и автоустановки APK. Отключается в настройках.

## Требования и совместимость

- **Android 16 (API 36)** и совместимая сборка Nothing OS System UI.
- Совместимая реализация LSPosed/Xposed, поддерживающая требования модуля к legacy API (**API 93+ и New XSharedPreferences**).
- Работающий `su` нужен только для освобождения/восстановления Essential Key через приложение. **Меню питания, диктофон и остальные хуки не запрашивают root у приложения.** Диктофон требует разрешение на микрофон. `QUERY_ALL_PACKAGES` нужен для локального списка установленных приложений и экспортируемых Activity; этот список никуда не отправляется.

**Основное устройство и конфигурация:** CMF Phone 2 Pro, сборка `Galaga-B4.1-260812-1729` (по данным автора). Предоставленный `NothingSystemUI.apk` изучен статически: версия пакета `16.0.0`, SHA-256 `7e0c584a22ca82000343a5bec356a6f0d2468cd377092d2d261dec05a92093ec`. Статический анализ **не доказывает**, что каждая функция работает на устройстве. Полный набор испытаний на телефоне и совместимость с другими моделями Nothing/CMF пока не подтверждены.

Подробнее: [совместимость](docs/COMPATIBILITY.md), [проверки](docs/VALIDATION.md) и [план тестирования на устройстве](docs/DEVICE-TEST.md).

## Установка

1. Установите APK и включите модуль в совместимом менеджере LSPosed.
2. Добавьте в область действия **System UI** (`com.android.systemui`) и **Essential Tweaks** (`moe.xWey10.tweaks`). Для хуков скриншотов и Essential Key добавьте **System Framework** (`android`).
3. Перезагрузите телефон, откройте Essential Tweaks и включите необходимые функции.
4. Проверяйте изменения осторожно. Не используйте перезагрузку в Recovery/Bootloader, если у вас нет надёжного способа восстановить устройство при проблеме.

## Сборка из исходников

Потребуются **JDK 17+**, Android SDK **Platform 36** и **Build Tools 36.0.0**. В проекте закреплены Gradle 8.13, Android Gradle Plugin 8.13.2 и Kotlin 2.2.21.

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk` (подписывается локальным отладочным ключом).

Для сборки релизного APK:

```bash
./gradlew :app:assembleRelease
```

Для локальной сборки и подписи **существующим ключом**:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export KEYSTORE_PATH="$HOME/android-keys/essential-tweaks.jks"
export KEY_ALIAS="essential-tweaks"
./scripts/build-signed-release.sh
```

Скрипт сам прочитает `versionName` из `app/build.gradle.kts`, спросит пароль и сохранит `dist/EssentialTweaks-v<версия>.apk`. Готовый релизный APK необходимо подписать **собственным постоянным ключом**. Не публикуйте ключи подписи, пароли и приватные настройки. Для обновления уже установленного APK без удаления Android обычно требует тот же сертификат подписи. Архив исходников не является подписанным релизом.
