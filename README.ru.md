# Essential Tweaks

[English](README.md) · **Русский**

Essential Tweaks — неофициальный LSPosed-модуль для Nothing OS на Android 16. Он добавляет отдельные настройки штатного интерфейса, **не заменяя System UI целиком**.

**Версия:** 0.2.18 · **Лицензия:** [GPL-3.0-only](LICENSE) · **Статус:** экспериментальный

Проект не связан с Nothing или CMF и не поддерживается ими. После обновлений прошивки системные хуки могут перестать работать — включайте и проверяйте функции по отдельности.

## Возможности

- **Меню питания:** дополнительные действия для перезагрузки в Recovery, Bootloader и перезапуска System UI в штатном меню, с подтверждением и проверками безопасности.
- **Индикатор отпечатка:** собственная картинка вместо индикатора подэкранного сканера в режиме ожидания и настройка цвета точек при сканировании.
- **Экран блокировки:** отображение напряжения, тока, мощности и температуры зарядки, а также пробуждение и выключение экрана двойным касанием.
- **Essential Key:** назначение скриншота или записи экрана на нажатие, двойное нажатие, удержание, нажатие с последующим удержанием и два нажатия с последующим удержанием. Штатное поведение кнопки можно вернуть: модуль включает обратно Essential Space и Essential Recorder и сбрасывает собственные назначения.
- **Скриншоты:** необязательный хук System Framework, ослабляющий ограничение `FLAG_SECURE` для окон приложений. Он **не обходит DRM** (пока что) и не гарантирует захват содержимого любого приложения.
- **Проверка обновлений:** проверка опубликованных стабильных [GitHub Releases](https://github.com/xWey10/Essential-Tweaks/releases) и сообщение о новой версии **только внутри приложения**. Автопроверка происходит при открытии приложения не чаще раза в 24 часа после успешного запроса. Есть ручная проверка и переключатель автопроверки. Android-уведомлений, фонового сервиса обновлений и автоматической установки APK нет. Для проверки приложение напрямую обращается к GitHub.

## Требования и совместимость

- **Android 16 (API 36)** и совместимая сборка Nothing OS System UI.
- Совместимая реализация LSPosed/Xposed, поддерживающая требования модуля к legacy API (**API 93+ и New XSharedPreferences**).
- Работающий `su` для привилегированных операций — например, освобождения/восстановления Essential Key и некоторых вариантов перезагрузки. Для самого хука скриншотов приложению не нужен отдельный root-доступ.

**Основное устройство и конфигурация:** CMF Phone 2 Pro, сборка `Galaga-B4.1-260812-1729` (по данным автора). Предоставленный `NothingSystemUI.apk` изучен статически: версия пакета `16.0.0`, SHA-256 `7e0c584a22ca82000343a5bec356a6f0d2468cd377092d2d261dec05a92093ec`. Статический анализ **не доказывает**, что каждая функция работает на устройстве. Полный набор испытаний на телефоне и совместимость с другими моделями Nothing/CMF пока не подтверждены.

## Установка

1. Установите APK и включите модуль в совместимом менеджере LSPosed.
2. Добавьте в область действия **System UI** (`com.android.systemui`) и **Essential Tweaks** (`moe.xWey10.tweaks`). Для хуков скриншотов и Essential Key добавьте **System Framework** (`android`).
3. Перезагрузите телефон, откройте Essential Tweaks и включите необходимые функции.
4. Проверяйте изменения осторожно. Не используйте перезагрузку в Recovery/Bootloader, если у вас нет надёжного способа восстановить устройство при проблеме.
